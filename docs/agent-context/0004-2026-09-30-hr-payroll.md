# HR payroll ("Planilla") from hourly pay — 2026-09-30

Delta handoff. Builds on [0003](./0003-2026-09-02-hr-module.md) (HR module).
Since 0003 the module also gained the read-only employee portal, time-off
requests and admin punch corrections (commit 7d2aa97, migrations 0045/0046).

---

## What it is

Each employee has a **salario por hora** on their profile. `/admin/rrhh/planilla`
multiplies the hours they punched by that rate for a **semana** (Mon–Sun),
**quincena** (1–15 / 16–end) or **mes**, and shows the salario bruto per
employee with an expandable per-day breakdown. Nothing is stored — the page is
recomputed on every load, so a punch correction or a new rate shows up
immediately.

## Rates (migration 0054, `hr_pay_rates`)

- Dated history, not a column: `(employee_id, hourly_rate, effective_from)`,
  unique per employee+date. A raise "rige desde" a date, so older periods keep
  their old rate. Re-saving the same date replaces the entry (typo fix).
- `rateEntryOn(rates, date)` = latest entry with `effective_from <= date`; days
  **before the first entry use the first entry** (hours worked before the admin
  typed a rate still get paid).
- Set in the employee modal (create/edit) on `/admin/rrhh`. The first rate
  needs no date; changing an existing one asks "Rige desde".
- RLS: admin (`is_app_admin()`) and the employee (own rows) read; no write
  grants — writes are service-role in `createEmployeeAction` /
  `updateEmployeeAction`. anon has no grant at all, so an anon render of an
  admin page logs a 42501 before the layout redirect wins (same as the other
  locked-down tables).

## Rules (`lib/services/hr-payroll.ts`, pure `computeEmployeePayroll`)

Per CR calendar day, then summed:

- **pagado** = asistencia "Trabajado" + break up to the schedule's `breakMin`
  (breaks are tiempo efectivo; the excess is unpaid). Lunch is unpaid.
- **ordinarias** = pagado up to the jornada `end − start − lunch` on a
  scheduled workday; **0 on a non-workday**.
- **extra** = the rest, at **1.5×** (Código de Trabajo art. 139).
- No schedule → `DEFAULT_SCHEDULE` (8–17, L–V), tagged "Horario por defecto".
  A schedule with no time left after lunch (e.g. the 08:00→05:00 test row) →
  8 h legal jornada, tagged "Revisar horario"; `saveEmployeeScheduleAction` now
  rejects such schedules.
- Open day: today → "En curso" (not counted yet); past → "incomplete", **not
  paid** until corrected in Asistencia (link from the breakdown).
- Money in **céntimos**, rounded per day, so days → employee → total add up.
- Gross only: no CCSS/renta deductions, feriados/rest-day double pay,
  vacation/incapacidad pay or aguinaldo. Approved leave days are listed, not paid.

## Related fix

`computeDaySummary` now sums entrada→salida **sessions** instead of first
entrada → last salida, so a salida + new entrada (errand, or "salida" punched
at lunch) no longer counts the gap as worked. Affects Asistencia and Mis horas
too; single-session days are unchanged.

`fetchAllPunchesInRange` pages with `count: 'exact'` — PostgREST caps responses
(1000 rows), and a month of staff punches passes that.
